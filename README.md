# coopon

飯田橋のカフェ・ファミレス・コンビニと公式クーポン。

**公開サイト:** https://a24z7km.github.io/coopon/

スマートフォン・PCのブラウザで利用できます。ログイン不要です。

## ローカルで起動

```sh
python3 -m http.server 4173
```

http://localhost:4173/ を開きます。ビルドやAPIキーは不要です。

## ファイル

- `index.html` / `style.css` / `app.js`: 画面と操作
- `store-data.js`: 公式情報で確認した飯田橋周辺の7店舗
- `coupon-data.js`: 公式発表に基づくクーポン情報

店舗・クーポン情報は2026年11月1日時点の確認内容です。定期自動更新はありません。地図座標は国土地理院の住所検索を利用し、一部は街区代表位置です。割引の適用条件・対象店舗は公式アプリや紙の券をご確認ください。

地図はLeafletとOpenStreetMapを利用しています。現在地はボタンを押して許可した場合のみ取得し、保存しません。現在地の取得にはHTTPSまたはlocalhostが必要です。

## 公開

GitHub Pagesの公開元は `main` ブランチのルートです。`main` への更新がサイトに反映されます。

## クーポン収集

ファミマの公開クーポンを14件取り込む収集器を追加しました。

```sh
python3 scripts/collect-family-coupons.py
python3 -m unittest discover -s tests
```

`coupon-feed.js`が更新されます。GitHubへpushするとPagesに反映されます。定期実行は未設定です。
取得範囲と今後の拡張方針は [公式クーポンの取得方法](docs/coupon-acquisition.md) を参照してください。
